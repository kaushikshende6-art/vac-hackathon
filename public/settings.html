🚀 Render / Cloud Deployment Guide

To deploy TRACKX to Render.com for free hackathon hosting:

  1. Push this repository to GitHub.
  2. In Render Dashboard, create a new Web Service and connect your repo.
  3. Set Build Command: npm install
  4. Set Start Command: npm start
  5. Copy your resulting Render URL and paste it into the Arduino firmware configuration below!
